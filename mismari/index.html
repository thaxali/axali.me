About the face

Mismari is a unicase display typeface built from thin strokes and sharp, triangular terminals — letters that read as though they were chiselled rather than drawn. Its name comes from the Arabic mismar, ‘nail’, the same root behind the wedge-pressed script of cuneiform.

With a single case and a compact set of forms, it is made for headlines, marks, and monograms where character matters more than text.
